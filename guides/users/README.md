# Which guide is mine?

Answer the first question that fits you.

```text
Do you decide whether, or how, your country or organisation joins?
   └─ yes → Decision-maker
Do you run the central server, the CA or the timestamp service?
   └─ yes → Authority operator
Does your organisation OFFER data or a service to others?
   └─ yes → Data provider
Do you write an application that CALLS someone else's service?
   └─ yes → Consumer developer
Are you a small organisation that uses a vendor's node and keeps its own key?
   └─ yes → Hosted member
Do you run a node for other organisations?
   └─ yes → Node operator
Do you check that everyone followed the rules?
   └─ yes → Auditor
Are you a person who wants to know who looked at YOUR data?
   └─ yes → Citizen
Are you building the website or app that shows citizens that answer?
   └─ yes → Citizen portal developer
```
