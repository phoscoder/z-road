# Security policy

Z-Road is an early proof of concept and has not been independently reviewed.
Do not use it with real data yet. See [docs/threat-model.md](docs/threat-model.md)
for what is and is not defended against.

If you find a vulnerability, please do **not** put exploit details in a public
issue. Open an issue that only says you have a security report and ask for a
private channel, or use GitHub's private vulnerability reporting for this
repository if it is enabled.
